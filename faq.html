Questions

Everything people ask before trusting Excel with the numbers.

Honest answers about formats, versions, delivery, data handling and what happens after handover. If something is missing, ask — the reply comes from me, not a support queue.

The basics

Is this a real Excel file or an online app?
A real .xlsx workbook that opens in Microsoft Excel (2016 or later, or Microsoft 365). The website demos are simulations of the logic; the product itself is a file you download, keep and own.
Do I need a Microsoft 365 subscription?
A desktop Excel install is required. Most systems use formulas and Power Query only, both included in Excel 2016+ and Microsoft 365. If your build needs Power Query and you are on a very old version, I will tell you before you pay.
Does it work on Mac?
Yes for the formula-driven systems. Power Query works on modern Excel for Mac; VBA behaves slightly differently, so Mac-specific builds are tested on Mac.
Will it work in Google Sheets or LibreOffice?
Some systems import into LibreOffice Calc with reduced functionality. Google Sheets is not supported because Power Query and structured tables do not exist there.

Buying and delivery

How long does delivery take?
Catalog systems: 5–10 working days from approved scope. Custom builds: usually 2–4 weeks depending on data cleanup and the number of users.
What do I receive?
The workbook (with sample data replaced by yours where relevant), a written manual, a walkthrough call or recording, and a backup routine. Custom builds also include the blueprint document.
Can I buy more than one system?
Yes. Buying two or more catalog systems together is discounted — ask for a combined quote. Systems can also be linked so that sales update inventory automatically.
How is the file transferred?
Email, or a shared OneDrive/Google Drive folder if the file is large. You get the final file, not a link that expires.

Data and privacy

What happens to my business data?
It is used only to build and test your system on my machine, then deleted once the project is closed — unless you ask me to keep the working copy for support.
Can you sign a confidentiality agreement?
Yes. Send yours, or ask for a short mutual NDA before sharing files.
Is the workbook secure?
Sheets are protected and inputs validated to prevent accidental damage. That is protection against mistakes, not against a determined person — no Excel file is encrypted unless you set a password, which I recommend.

After handover

What if a formula breaks later?
Every build includes a support window (14–60 days depending on the package). After that, small fixes are quoted as mini-jobs, or covered by optional support at €60/month.
Can I edit it myself?
Yes — it is your file. The structure is documented so you can add products, categories or users without breaking anything. Larger structural changes are best done together.
Do you keep working with the business after delivery?
Only if you want to. Many clients come back for a second system six months later; nothing requires it.
What if I outgrow Excel?
Then you will need a different tool, and that is a good sign. I will happily tell you when a workbook stops being the right answer — the file stays yours either way.
